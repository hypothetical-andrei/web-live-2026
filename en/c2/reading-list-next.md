# Reading list for the next lecture — Lecture 03 — Modules, Asynchrony, Events and the Browser

Complete these readings before Lecture 03 — Modules, Asynchrony, Events and the Browser.

- [MDN: JavaScript modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules) — understand module scope, imports, exports, and browser loading.
- [MDN: Using promises](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Using_promises) — trace asynchronous fulfillment, rejection, and composition.
- [MDN: Using the Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) — separate network failures, HTTP outcomes, and body parsing.
- [MDN: Event bubbling](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Event_bubbling) — reason about propagation, delegation, `target`, and `currentTarget`.
