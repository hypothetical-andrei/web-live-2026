# Deeper understanding — Lecture 01 — The Web as a System + AI-Assisted Development

Use these readings after the lecture to revisit its concepts in more depth.

- [MDN: Overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview) — connect clients, servers, intermediaries, requests, and responses.
- [MDN: HTTP messages](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Messages) — identify the start line, headers, and body in requests and responses.
- [MDN: HTTP response status codes](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status) — interpret status classes and the specific statuses used in the lecture.
- [Chrome DevTools: Inspect network activity](https://developer.chrome.com/docs/devtools/network/) — gather browser-side evidence about an HTTP exchange.
- [MDN: HTTP request methods](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Methods) — compare method semantics, safety, and idempotence.
- [OpenAI Docs: Gemini prompting](https://developers.openai.com/codex/prompting/) — frame coding tasks with useful context, constraints, and verification expectations.
