# Reading list for the next lecture — Lecture 02 — JavaScript for Reading and Modifying Programs

Complete these readings before Lecture 02 — JavaScript for Reading and Modifying Programs.

- [MDN: Grammar and types](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Grammar_and_types) — review values, declarations, scope, objects, arrays, and destructuring.
- [MDN: Working with objects](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Working_with_objects) — distinguish object identity, properties, and copying behavior.
- [MDN: Inheritance and the prototype chain](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Inheritance_and_the_prototype_chain) — prepare to trace delegated property lookup and relate classes to prototypes.
- [MDN: Closures](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Closures) — explain how functions retain access to lexical scope.
