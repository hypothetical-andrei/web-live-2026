# Reading list for the next lecture — Lecture 05 — Server-Side JavaScript and REST APIs

Complete these readings before Lecture 05 — Server-Side JavaScript and REST APIs.

- [Node.js: Introduction to Node.js](https://nodejs.org/en/learn/getting-started/introduction-to-nodejs) — distinguish the Node runtime from browser JavaScript.
- [Express: Basic routing](https://expressjs.com/en/starter/basic-routing.html) — map methods and paths to route handlers.
- [Express: Using middleware](https://expressjs.com/en/guide/using-middleware.html) — trace request flow and middleware ordering.
- [Express: Error handling](https://expressjs.com/en/guide/error-handling.html) — place centralized error handling at the end of the pipeline.
