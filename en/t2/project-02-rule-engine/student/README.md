# Rule Engine

Run `npm install`, the focused checks, `npm run evaluate`, and `npm test`. The runner reads `data/scenario.json` and writes `data/result.json` without command-line arguments. Implementations belong only in `src/rule-engine.js`.

Use the project-level README for the staged AI workflow. Student work begins with a no-edit analysis of rule shapes, closure capture, recursion, and short-circuiting, followed by a bounded one-file change and independent verification.
