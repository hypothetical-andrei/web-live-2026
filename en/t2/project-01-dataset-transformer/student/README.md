# Dataset Transformer App

Run `npm install`, then `npm start` and the focused checks. The app uses an in-memory sample and has no file or argument interface. The only implementation boundary is `src/transform-tasks.js`.

Use the project-level README for the staged AI workflow. Student work begins with a no-edit explanation of the array pipeline and its value shapes, followed by a bounded one-file change and independent verification. Do not edit the app, tests, or dependencies.
