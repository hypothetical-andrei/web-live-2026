# Aprofundare — Cursul 05 — JavaScript pe server și API-uri REST

Folosește aceste materiale după curs pentru a relua conceptele în profunzime.

- [MDN: Coduri de stare ale răspunsurilor HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status) — proiectează contracte consecvente pentru succes și eșec.
- [RFC 9110: Semantica HTTP](https://www.rfc-editor.org/rfc/rfc9110) — consultă definițiile normative ale metodelor, câmpurilor și codurilor de stare.

- [Tratarea erorilor în Express 5](https://expressjs.com/en/5x/guide/error-handling/) — compară promisiunile returnate, callback-urile și cazul antetelor deja trimise cu exemplul 06.
- [API-ul Joi](https://joi.dev/api/18.x.x) — examinează câmpurile obligatorii, cheile necunoscute, conversia și rezultatele validării; exemplul 05 fixează versiunea compatibilă Joi 17.13.8.
- [OpenAPI 3.1.1](https://spec.openapis.org/oas/v3.1.1.html) — citește obiectele Paths, Operation, Request Body și Responses lângă fișierul JSON al exemplului 05.
- [Încapsularea în Fastify](https://fastify.dev/docs/latest/Reference/Encapsulation/) — compară vizibilitatea pluginurilor cu middleware-ul Express ordonat pe care l-ai urmărit. Comparația este opțională.

- [Fielding: stilul arhitectural REST](https://ics.uci.edu/~fielding/pubs/dissertation/rest_arch_style.htm) — distinge constrângerile arhitecturale de convențiile CRUD.
- [Modelul de maturitate Richardson](https://martinfowler.com/articles/richardsonMaturityModel.html) — compară resursele, semantica HTTP și hipermedia; nu este un standard de conformitate REST.
- [RFC 9110: negocierea conținutului](https://www.rfc-editor.org/rfc/rfc9110.html#section-12) — leagă Accept, valorile de calitate și Vary de exemplul JSON/CSV al colecției.
