# Rule Engine

Rulează `npm install`, verificările țintite, `npm run evaluate` și `npm test`. Runnerul citește `data/scenario.json` și scrie `data/result.json` fără argumente în linia de comandă. Implementările aparțin doar lui `src/rule-engine.js`.

Folosește README-ul proiectului pentru fluxul IA etapizat. Lucrul începe cu analiza fără editări a formelor regulilor, capturii închiderilor, recursivității și scurtcircuitării, urmată de o schimbare delimitată într-un singur fișier și verificare independentă.
