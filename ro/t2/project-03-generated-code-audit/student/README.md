# Auditarea codului generat

Rulează `npm install`, `npm run compare` și verificările țintite. Păstrează `unsafe-generated.js`; remedierile aparțin doar lui `safe-normalizer.js`.

Folosește README-ul proiectului pentru fluxul IA etapizat. Lucrul începe cu un tabel al defectelor, fără editări, care acoperă conversia, proprietățile moștenite, mutația, aliasurile și ordonarea, urmat de o schimbare delimitată într-un singur fișier și verificare independentă. Păstrează artefactul nesigur.
