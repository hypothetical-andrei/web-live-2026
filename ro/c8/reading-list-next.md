# Lista de lecturi pentru cursul următor — Cursul 09 — Rutare, formulare și React full-stack

Parcurgeți aceste materiale înainte de Cursul 09 — Rutare, formulare și React full-stack.

- [React Router: Routing](https://reactrouter.com/start/declarative/routing) — definiți arbori de rute, rute imbricate, parametri și linkuri.
- [React Router: Navigating](https://reactrouter.com/start/declarative/navigating) — comparați linkurile, redirectările și navigarea programatică.
- [React: Sharing state between components](https://react.dev/learn/sharing-state-between-components) — plasați starea formularului și a vizualizării sub un proprietar explicit.
- [MDN: Using the Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) — implementați limita protocolului din spatele unui adaptor de date UI.
