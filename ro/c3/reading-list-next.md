# Lista de lecturi pentru cursul următor — Cursul 04 — HTML, CSS, interfețe responsive și accesibilitate

Parcurgeți aceste materiale înainte de Cursul 04 — HTML, CSS, interfețe responsive și accesibilitate.

- [MDN: Structurarea documentelor](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Structuring_documents) — alegeți elementele semantice după sensul conținutului, nu după aspect.
- [WAI: Tutorial despre formulare](https://www.w3.org/WAI/tutorials/forms/) — construiți formulare accesibile folosind etichete, instrucțiuni, validare și grupare.
- [MDN: Cascada CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Introduction) — urmăriți originea, importanța, straturile, specificitatea și ordinea în sursă.
- [MDN: Modelul casetei CSS](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model) — anticipați dimensiunile randate și diagnosticați depășirea spațiului disponibil.
