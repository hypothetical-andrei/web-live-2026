# Lista de lecturi pentru cursul următor — Cursul 02 — JavaScript pentru citirea și modificarea programelor

Parcurgeți aceste materiale înainte de Cursul 02 — JavaScript pentru citirea și modificarea programelor.

- [MDN: Gramatică și tipuri](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Grammar_and_types) — recapitulați valorile, declarațiile, domeniul lexical, obiectele, array-urile și destructurarea.
- [MDN: Lucrul cu obiecte](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Working_with_objects) — deosebiți identitatea obiectelor, proprietățile și comportamentul copierii.
- [MDN: Moștenirea și lanțul prototipurilor](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Inheritance_and_the_prototype_chain) — pregătiți-vă să urmăriți căutarea delegată a proprietăților și să legați clasele de prototipuri.
- [MDN: Închideri](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Closures) — explicați cum păstrează funcțiile accesul la domeniul lexical.
