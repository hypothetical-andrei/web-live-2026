# Lista de lecturi pentru cursul următor — Cursul 08 — React cu Vite

Parcurgeți aceste materiale înainte de Cursul 08 — React cu Vite.

- [React: Describing the UI](https://react.dev/learn/describing-the-ui) — învățați componente, JSX, props, condiții și randarea listelor.
- [React: Adding interactivity](https://react.dev/learn/adding-interactivity) — urmăriți cum evenimentele modifică starea și duc la actualizarea interfeței.
- [React: Updating objects in state](https://react.dev/learn/updating-objects-in-state) — actualizați obiectele din stare prin crearea unor copii, fără a modifica obiectele existente.
- [React: Synchronizing with effects](https://react.dev/learn/synchronizing-with-effects) — folosiți efectele pentru sincronizarea cu sisteme externe și urmăriți rolul funcției de curățare.
