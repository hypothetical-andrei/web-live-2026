Acțiuni față de resurse

Ruterul naiv nemontat folosește POST /register și POST /unregister, ascunzând identitatea și semantica reîncercării.

URL-ul canonic imbricat identifică o apartenență sesiune–participant. PUT și DELETE exprimă stări țintă idempotente. URL-urile imbricate sunt utile aici deoarece sesiunea este centrală, dar reprezintă o alegere de proiectare, nu o regulă universală.
