# Lecturi pentru cursul următor — Cursul 03 — Module, asincronie, evenimente și browserul

Parcurge aceste materiale înainte de Cursul 03 — Module, asincronie, evenimente și browserul.

- [MDN: Module JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules) — înțelege domeniul modulului, importurile, exporturile și încărcarea în browser.
- [MDN: Utilizarea promisiunilor](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Using_promises) — urmărește îndeplinirea, respingerea și compunerea asincronă.
- [MDN: Utilizarea API-ului Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) — separă eșecurile de rețea, rezultatele HTTP și parsarea corpului.
- [MDN: Propagarea evenimentelor](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/Event_bubbling) — analizează propagarea, delegarea, `target` și `currentTarget`.
